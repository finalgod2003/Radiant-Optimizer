# 0.2.0 Preview 验收记录

日期：2026-10-10。对应已批准的第二阶段：CS2、Fortnite、VALORANT 游戏配置，以及硬件持续监控、PresentMon 帧采集、浮层和本地导出。

## 已交付

- 游戏配置：已知目录发现与手动选文件、竞技/均衡预设、逐项差异预览、原始字节备份、应用、恢复与冲突提示。格式范围见 [游戏支持说明](game-profile-support.md)。未知版本、缺失必要键、运行中的游戏、只读或链接路径、预览后内容变化会阻止写入。
- 高级监控：CPU/RAM 持续采样、CPU 趋势、显卡选择、Windows GPU 活动与显存、受支持的 NVIDIA NVML 温度；暂停/恢复和最多 600 条传感器历史，可免费导出 CSV。
- 帧采集：固定版本 PresentMon 2.6.0，按 PID 和启动时间验证目标，平均 FPS、帧时间 P95/P99、1% low，独立置顶/可拖动/鼠标穿透浮层及帧 CSV。采集最多 5 分钟或 60,000 帧。方法和限制见 [监控说明](monitoring-support.md)。
- 授权：游戏预设应用、FPS 采集、浮层和帧 CSV 需要 Premium；检测、预览、传感器历史与 CSV、已有记录恢复免费。游戏写入沿用每次启动默认关闭的实验开关与逐次确认。
- 网站：中英文功能、价格、下载、隐私和支持矩阵已同步；游戏目录继续位于 `/games`。

- 中英文功能/价格/下载页面验证通过。390 px 移动布局与桌面布局未发现横向溢出；支持矩阵可阅读，免费传感器 CSV 与付费帧 CSV 范围一致。
- 开发服务 `http://localhost:3010` 与临时生产服务 `http://localhost:3011` 获取到相同 0.2 包，完整下载后 SHA-256 一致。当前购买入口保持关闭。

### 帧采集验证边界

本机隐藏 D3D11 测试程序成功调用 Present 33 次，但 PresentMon 实时 ETW 启动被 Windows 拒绝（退出码 6，access denied）；当前账号没有所需权限，实际收集 0 帧，界面不会产生虚构 FPS。本轮没有自动提权或修改用户组。因此**实时游戏帧采集、游戏中浮层显示及独占全屏兼容性未完成实机验收**。

另使用 [PresentMon 2.6.0 官方 ETL 样本](https://github.com/GameTechDev/PresentMon/blob/v2.6.0/Tests/Gold/test_case_2.etl) 离线重放，读取 97 行记录，全部 PID、交换链、时间戳和帧间隔与官方 gold CSV 相同。样本 SHA-256 为 `71194538cf20cce3ada1febce98dd12e978920db00adee7fdd1af2886983faf3`。此检查验证工具与解析器配合，不能替代当前电脑上的实时采集成功验收。

FPS 是应用呈现事件的频率，包含丢弃帧，不代表物理显示帧率或输入延迟。浮层为独立窗口，面向窗口/无边框模式。清理测试后无本产品启动的 PresentMon 进程或 ETW 会话残留；原有第三方监控进程未受影响。

### 游戏兼容性边界

本机未启动这三款游戏完成配置消费验收。当前支持的是明确识别的文件格式：CS2 `video.cfg` Version 15/16、Fortnite `FortniteReleaseVersion=14`（如有 `Version` 须为 5）、VALORANT `LocalSettingsVersion=5/7`。文件事务和恢复已验证，**不等同于所有当前线上版本或游戏更新后的兼容认证**。未知格式保持只读；正式扩展前需针对安装的目标游戏版本验证。
