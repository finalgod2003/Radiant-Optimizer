## 浏览器与本机

- 验证中英文页面、首页交互、小屏 390 px 与桌面布局；关键页面未出现横向溢出。
- 浏览器完成登录、无授权空状态、设备码确认、授权设备显示、解绑、管理员撤销。
- 普通账号访问管理员授权页正确返回用户授权中心；`/settings` 默认进入授权中心。回归未再出现重复跳转错误。
- 登录、注册、找回密码的服务端 HTML 使用 POST，脚本接管前禁用提交；真实登录后的 URL 不含凭据。敏感资料/重置表单同样使用 POST。
- 用户授权及管理员授权查询按用户 ID 隔离缓存，管理员翻页占位数据不跨用户复用。
- Windows 11 打包程序执行真实只读硬件/进程诊断成功；七个中文页面完成离屏渲染并检查主要布局。
- 没有在用户电脑上执行注册表或电源计划写入。该能力仍需在可回滚的 Windows 测试环境完成系统级验收，预览客户端默认关闭实验性写入。

本地原始日志、HTTP 校验结果和七页客户端图片保存在忽略目录 `artifacts/verification/`。诊断包含本机硬件/进程信息，不纳入版本库。

## 安全复核

已使用项目 `security-scan` 的脚本及变更清单复核；确定性扫描覆盖 129 个变更文件，无发现。对授权、支付回调、恢复日志、设备 API 和登录变更进行了代码复核，并通过相关回归检查。此结果不等同于生产渗透测试。

| 级别   | 位置           | 问题                                  | 修复或结论                                                           |
| ------ | -------------- | ------------------------------------- | -------------------------------------------------------------------- |
| 已修复 | 客户端离线授权 | 缓存不能提供自身信任根                | 公钥改为构建时嵌入；伪造、未知公钥缓存拒绝测试通过                   |
| 已修复 | 客户端状态文件 | 损坏缓存影响启动/恢复入口             | 保留不可读文件并降级免费，恢复入口可用；串行化凭据更新               |
| 已修复 | 设备 API       | 可变 Cookie 身份与无界限流状态        | 使用可信连接地址、限制桶数量、过期清理和请求体大小                   |
| 已修复 | 认证与授权网页 | 水合前 GET 提交、权限循环、跨用户缓存 | POST 与初始禁用、稳定导航与单次跳转、账号隔离缓存                    |
| 通过   | 文件与配置     | 未发现新增私钥或凭据泄露              | 本地配置、签名私钥、数据库、凭据缓存及二进制均忽略；发布程序仅含公钥 |
