# 产品首页方向修正 · 2026-10-10

此记录根据用户最新确认，替代早期设计中“游戏目录为网站主体”的定位。完整产品设想见 `superpowers/specs/2026-10-10-radiant-product-design.md`；本轮客户端范围以用户批准的英文、真实硬件信息和只读检测首版为准。

## 已确认

- 网站推广我们自己的 Radiant Optimizer Windows 客户端。
- 下载、购买、付款确认和设备授权由本站承担，不把主转化导向外部官网。
- H1 必须包含完整关键词 Radiant Optimizer；代码通过 `envConfigs.app_name` 输出。
- 在线网页游戏用于引流，是辅助内容。产品页的首屏、主要导航和行动按钮优先服务产品。
- 用户已于 2026-10-10 选定 C / Midnight blue：深蓝背景、银白排版、产品大标题。方案已用于正式首页 `/`，原型保留在 `/design-preview` 作为参考。
- 最新语言要求：先做英文版，不考虑中文版。当前设计、文案、排版和验收以英文页面为准。
- 最新客户端要求：直接提供可运行的 Windows 首版，英文界面、真实硬件信息和只读检查。首页不再使用竞品截图；使用本仓库 WPF 程序自身渲染的界面。

## 原型的信息顺序

产品首屏 → 客户端功能与界面 → 免费版 / 专业版 → 下载 → 产品常见问题 → 在线游戏入口。

三版共用此结构与内容，比较的是排版和配色：A 暖白编辑式、B 蓝白产品展示、C 深蓝排版。三版首屏均出现完整产品名，主按钮为本站下载，专业版入口连接版本说明与本站购买流程预览。

## 已实施

- 正式首页采用 C，取消原型切换栏；H1、元数据和主下载入口围绕我们的客户端。
- 游戏目录迁至 `/games`，保留搜索、分类、收藏、计算器和 `/games/:id` 播放路径。游戏页导航、返回链接和 sitemap 已同步，配色与产品站一致。
- 首页介绍本轮实际可用的硬件详情、可解释检测和 HTML / JSON 报告；Premium 明确显示为规划中，不创建订单或收款。
- 客户端 0.2.0：硬件详情、显卡驱动与所有固定磁盘、检测筛选、可展开的建议、刷新取消和 F5 / Esc 快捷键、HTML / JSON 本地导出。默认深色，保留浅色。

## 下一阶段再实施

- 将本地便携预览版完善为签名发布包、版本化下载页和正式分发流程。
- 确认定价、版本能力和授权规则后，再接入本站付款、订单、授权及客户端激活。

## 当前发布边界

设计研究页 `/design-preview` 保留 `noindex, nofollow`，正式首页为 `/`。首页采用本地选定的视觉设计，下载与版本入口连接完整客户端的 `/download` 和 `/pricing`；价格使用现有产品目录，实际下载和付款仍由既有发布与支付配置决定。账号授权、设备激活、功能页和网页工具入口均保留。

独立唯读预览客户端位于 `desktop/preview/`，通过 `desktop/preview/build.ps1` 构建，输出到 `artifacts/windows-preview/` 和 `public/downloads/preview/`。界面图来自该 WPF 程序和本机真实读数，不包含设备序列号、主机名或网络标识，图注明确它与完整客户端下载包独立。预览版仅检查与导出报告；完整客户端的授权、游戏配置和监控实现保留在 `desktop/` 的其他项目中。

此轮未改变支付服务或数据库设计，也未部署到外部环境。
