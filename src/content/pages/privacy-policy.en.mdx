## Introduction

We respect your privacy and are committed to protecting your personal data. This Privacy Policy explains how we collect, use, and safeguard your information when you use our service.

## Information We Collect

We collect the following types of information to provide and improve our service:

1. **Account Information** — Your name, email address, and other details you provide when creating an account.
2. **Usage Data** — Information about how you interact with the service, including features accessed, frequency of use, and interaction patterns.
3. **Device Information** — Device type, operating system, and browser type, used to optimize compatibility and performance.
4. **Cookies** — Small data files stored on your device to remember preferences and improve your experience.
5. **Payment Information** — Billing details handled by trusted third-party payment processors. We do not store full card numbers on our servers.

## Windows client preview

Hardware and process readings, input-test results, original setting values and recovery records are processed locally. This preview does not automatically upload these readings or keyboard input records. Network tests send requests to the destination selected by the user when the test is started.

Game discovery reads configuration files in known local game locations or a file you select. Previews, file paths, original-file backups and change history remain on your computer. A backup preserves the complete original file, which can include game or account identifiers already present in it. Keep the local recovery folder until you no longer need to restore those changes; review a backup before choosing to share it.

Hardware monitoring reads system and supported driver sensors locally. When you start FPS capture, the included PresentMon tool reads Windows event-tracing data for the selected process. Capture files and CSV exports can contain process names and identifiers, timestamps, frame timings and hardware readings. These recordings are stored locally and are not automatically sent to the website or a third-party analytics service. Starting, stopping, exporting or deleting a local recording is under your control. The separate overlay displays local readings without injecting code into the game.

Premium activation sends the device name, a random installation identifier and short-lived activation codes to the server. The server stores license and order associations, device activity timestamps and revocation records. Device credentials are stored as hashes on the server; the client protects credentials and signed leases with the current Windows user's DPAPI. Website passwords are never passed to the desktop client. Website sign-in cookies, language preferences and configured website analytics are separate from local diagnostics.
